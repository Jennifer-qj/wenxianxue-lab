# 内容编辑区

这里是站点唯一的人工内容源。用户只需要编辑本目录中的 Markdown/YAML；组件、校验和构建逻辑位于 `src/` 与 `scripts/`。

- `outline/`：十四章最小知识单元，必须填写经纸本核验的页码。
- `chapters/`：原创章节导读与硬清单。
- `concepts/`：概念、载体、典籍、人物、事件和方法。
- `graph/`：带证据与置信度的关系。
- `quiz/`：九类题型。
- `labs/`：六种通用交互引擎的案例数据。
- `notes/`、`site/`：研究札记与作品说明。

在纸本页码未核验前，不要创建正式 MKU 数据；先使用 `docs/templates/` 中的模板在本地草拟。

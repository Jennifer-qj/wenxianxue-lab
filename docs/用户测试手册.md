# 文献学实验室用户测试手册

## 测试目标

判断第一次访问者能否理解项目定位、找到学习内容、操作非选择题练习、留下学习记录、判断内容可信度并找到反馈入口。测试对象是网站，不是参与者。

## 招募与准备

- 每轮邀请 3—5 位未参与开发的大学生，最好包含文献学初学者与完全不了解该书的人。
- 每人约 15—25 分钟；不记录姓名、学号、联系方式等个人信息。
- 打开网站的“参与用户测试”页。观察者准备纸笔或使用页面内的匿名记录框。

## 主持人开场白

> 今天测试的是网站，不是你。遇到找不到、看不懂或操作失败都很正常，而且这些正是我们需要观察的内容。请一边操作，一边说出你正在寻找什么、为什么点击这里。除非页面彻底卡住，我不会提示答案。

## 七个固定任务

1. 从首页进入十分钟项目导览；完成后，用自己的话说明它和“在线电子书”有什么不同。
2. 从首页出发，找到第五章中关于善本判断的学习单元。
3. 在知识图谱中找到“版本”和“校勘”的关系，并解释连接理由。
4. 进入互动实验室，完成一个不只是单项选择的练习。
5. 收藏或批注一个页面，再到札记中把它找回来。
6. 找到第二章的核验状态，并解释“待复核”意味着什么。
7. 找到内容纠错入口，走到提交前一步，不必真的发送。

## 结束访谈

任务结束后只问四个问题，尽量逐字记录回答：

1. 你觉得这个网站想解决什么问题？
2. 哪一个部分最可能让你愿意继续使用？
3. 哪里最困惑、最像机器生成或最不可信？
4. 如果下周再来，你最希望多出什么？

## 观察规则

- 不告诉参与者该点哪里，不解释界面上的术语。
- 记录可观察事实：停顿位置、返回次数、误点路径、原话和是否完成。
- 区分“参与者个人偏好”与“三人以上重复出现的阻碍”。
- 任务超过 4 分钟仍无进展，可以标记为受阻并进入下一项。

## 复盘指标

- 每项任务完成率与中位耗时。
- 首次点击是否走向正确区域。
- 出现两次以上的术语误解或导航绕路。
- 严重度：阻止任务、显著拖慢、轻微困惑、审美偏好。
- 每轮只优先修复 3—5 个高频高影响问题，修复后使用相同任务复测。

## 结果留档

页面可以导出包含七项任务与结束访谈的匿名 JSON，也可以复制 Markdown 摘要。只有经作者确认并实际修复的建议，才进入公开共校成果记录；未采纳意见也应在 GitHub 讨论中说明理由。

测试结束后，打开 `/usability/results/`，一次选择或拖入多份 JSON。汇总页只在当前浏览器读取文件，不会上传参与者记录；它会按受阻率与主观难度给出阅读顺序，并列出每项任务的完成率、中位耗时、观察记录和访谈原话。排序只是帮助定位材料，不能代替逐份阅读。

# 项目路线图

《文献学实验室》不是原书数字化翻页项目，而是一项以“学习设计、知识建模、证据推理与互动叙事”为核心的个人数字人文实践。

## 当前阶段：结构化公测版

- [x] 七条学习路径与十四章系统覆盖
- [x] 143 个学习单元、176 个概念词条与 98 条证据关系
- [x] 134 道九题型练习、错题本、间隔复习与章节掌握度
- [x] 六项旗舰实验、十五个章节案例与综合古籍鉴定案卷
- [x] 可拖动、筛选、寻路和导出子图的知识图谱
- [x] 全站搜索、相关检索词、近似纠错与复核状态筛选
- [x] 无账号的札记、收藏、最近浏览、学习工作台与统一档案备份
- [x] GitHub Pages 自动部署、质量门禁、贡献规范与公开项目材料

## 下一阶段

1. 为开放式题目补充示范答案、分层量规与多结论路径。
2. 逐章审计术语、定义、关系、页码与题目答案，输出“待纸本复核清单”。
3. 仅在许可清晰或公版条件明确时，引入古籍图像及图像标注案例。
4. 增加端到端测试、移动端手势测试、无障碍审计和性能预算。
5. 整理项目报告、英文摘要、架构图与面试展示脚本。

## 长期边界

- 不提供原书全文、扫描件或大段逐字转录。
- 未经纸本核验的页码与结论必须明确标记。
- 暂不接入登录、用户画像和第三方访客追踪。
- 第三方图像权利不明确时不进入公开仓库。

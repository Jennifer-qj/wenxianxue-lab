# 文献学实验室试用邀请模板

## 私聊版

我最近在做一个面向文献学初学者的互动学习网站，想请你帮我做一次真实试用。它不是考试，也不需要你懂文献学；我主要想看第一次访问的人能不能理解页面、找到内容并完成互动。

大约需要 20 分钟。最好用电脑打开下面的“参与用户测试”页面，按顺序完成七个小任务；遇到找不到、看不懂或觉得很像机器生成的地方，请直接记下来，不用照顾我的感受。记录只保存在你的浏览器，除非你主动复制或导出。

测试入口：https://jennifer-qj.github.io/wenxianxue-lab/usability/

如果时间有限，也可以只走十分钟项目导览，然后告诉我三件事：你觉得它在解决什么问题、哪里最有用、哪里最不可信。

## 群聊／朋友圈版

想招募 3—5 位同学帮我试用一个个人数字人文项目：《文献学实验室》。无需文献学基础，不是请大家夸界面，而是想观察第一次访问时会在哪里犹豫、绕路或误解。完整测试约 20 分钟，也可以只体验十分钟导览。欢迎非常具体地挑错：内容看不懂、功能不好用、表述像 AI、证据不可信都可以。

测试入口：https://jennifer-qj.github.io/wenxianxue-lab/usability/

项目首页：https://jennifer-qj.github.io/wenxianxue-lab/

## 观察者速记

- 不告诉参与者应该点哪里。
- 让对方边操作边说出正在找什么。
- 记录原话、停顿、返回和误点，不只记“好／不好”。
- 单项超过四分钟仍无进展，标为“受阻”并继续下一项。
- 结束后使用页面内的四个访谈问题，不临时扩展成知识考试。

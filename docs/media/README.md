# 项目展示截图

本目录保存《文献学实验室》的对外展示截图，统一采用 1440×900 桌面视口。

推荐使用顺序：

1. `01-home.png`：项目首页与整体视觉。
2. `02-guide.png`：十分钟使用路线。
3. `03-coverage.png`：十四章系统覆盖。
4. `04-graph.png`：知识图谱与数字人文特征。
5. `05-lab.png`：互动实验室与非选择题任务。
6. `06-chapter.png`：章节内容、学习单元和练习闭环。

对外发布时建议首图使用 `01-home.png`，正文依次选择覆盖页、图谱、实验室和章节页；不必一次放完全部截图。

截图仅展示网站原创界面与学习内容，不包含原书扫描页或大段转录。

# 项目展示截图

本目录保存《文献学实验室》的对外展示截图。常规页面采用 1440×1000 桌面视口，代表章节采用 1440×1600 长画布，以同时呈现章节导读和专属学习模块。

推荐使用顺序：

1. `01-home.png`：项目首页与整体视觉。
2. `02-guide.png`：同页推进的十分钟项目导览。
3. `03-coverage.png`：十四章系统覆盖。
4. `04-graph.png`：知识图谱与数字人文特征。
5. `05-lab.png`：互动实验室与非选择题任务。
6. `06-chapter.png`：第一章阅读草图与研究问题入口。
7. `07-story.png`：第一人称作者手记与项目缘起。
8. `08-version.png`：第五章鉴定案卷式专属入口。
9. `09-catalog.png`：第七章目录著录卡式专属入口。

对外发布时建议首图使用 `01-home.png`，正文从作者手记、覆盖页、图谱、实验室和三个代表章节中按需要选择；不必一次放完全部截图。

截图仅展示网站原创界面与学习内容，不包含原书扫描页或大段转录。

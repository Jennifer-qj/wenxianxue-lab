## 可直接发布的正文

最近，我一直在做一件很“慢”，但也很有意思的事：把杜泽逊先生的《文献学概要（修订本）》重新组织成一个面向初学者的互动学习网站——《文献学实验室》。

项目的起点其实很简单。第一次读文献学教材时，我经常遇到三个问题：概念很多，读过以后不容易形成结构；版本、目录、校勘、辑佚和辨伪之间彼此关联，却很难只靠线性阅读看清；有些内容似乎“看懂了”，但真的遇到材料时，仍然不知道该怎样判断。

所以，我不想把原书做成一本可以在网页上翻页的电子书。那只是更换阅读介质，并没有改变学习方式。我更想尝试的是：能不能把一本专业教材变成一套“可以操作的知识”？

目前，网站已经整理覆盖全书十四章，并把内容拆分为 143 个结构化学习单元、176 个概念节点和 98 条带有证据与置信度标记的知识关系。读者既可以按七条学习路径进入，也可以直接搜索“版本”“校勘”“敦煌文献”等概念，再沿知识图谱观察它们如何跨章节连接。

为了避免学习停留在选择题，我还设计了多种互动任务：四部分类、版本鉴定、校勘判断、载体辨识、装帧排序、类书与丛书分拣，以及一份需要综合纸张、版式、避讳、刻工、藏印和著录证据的“古籍鉴定案卷”。这些任务不只是告诉你答案对错，还会解释证据为什么有效、结论为什么需要保留边界。

网站没有登录系统。练习、错题、研读和章节掌握度只保存在访问者自己的浏览器里，可以导出为 JSON 学习档案，也可以在其他设备恢复。这样既保持轻量，也尽量避免不必要的用户追踪。

对我来说，这个项目同时有两个目标：第一，帮助自己真正读完并理解这本书；第二，完成一次属于自己的数字人文实践。它涉及的不只是网页开发，还包括内容拆分、知识建模、教学设计、交互原型、版权边界和学术复核。

需要特别说明的是：网站不是《文献学概要》的在线复制，不公开原书全文、扫描件或大段转录。公开内容主要是原创概括、评论、元数据、自制图示和互动案例。十四章已经完成结构化覆盖，但部分精确页码与学术表述仍在依据纸本逐条复核，网站会明确标注相应状态。

这个项目还会继续生长。接下来我希望加入更多获得许可的古籍图像、图像标注、版本对勘案例和开放式任务示范，让它不仅能“查知识”，也能真正训练观察、比较和论证。

如果你也正在学习文献学、古典文献学或数字人文，欢迎来试用，也欢迎告诉我：哪一个概念最难理解？哪一种互动最能帮助你建立判断？
